# AI Resume Analyzer & Interview Preparer

An AI-powered full-stack web application that analyzes resumes against job descriptions and helps candidates prepare for interviews with personalized AI-generated insights.

## 🚀 Features

- 📄 Upload and analyze resumes
- 🤖 AI-powered resume analysis
- 🎯 Compare resume with a job description
- 📊 Generate personalized interview reports
- 💬 Interview preparation assistance
- 🔐 User authentication and authorization
- 🍪 Secure cookie-based authentication
- 📱 Responsive React interface
- ⚡ Fast and interactive UI

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router
- Axios
- Context API
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Multer

### AI & Other Technologies
- Google Gemini AI
- PDF parsing
- Puppeteer
- Zod
- REST APIs
